# Inventamos Labs Landing

Landing page estática para Inventamos Labs, lista para publicar en GitHub Pages.

## Archivos

- `index.html`: contenido y estructura principal.
- `styles.css`: estilos, responsive, paleta visual y componentes.
- `app.js`: menú móvil, animaciones al hacer scroll y año dinámico.
- `CNAME`: dominio personalizado `inventamoslabs.com` para GitHub Pages.
- `.nojekyll`: evita procesamiento Jekyll.

## Publicación rápida en GitHub Pages

1. Crea un repositorio, por ejemplo `inventamoslabs-landing`.
2. Sube todos estos archivos a la rama `main`.
3. En GitHub: Settings → Pages → Build and deployment → Source: `Deploy from a branch`.
4. Selecciona Branch: `main`, Folder: `/root`.
5. En Custom domain coloca `inventamoslabs.com`.
6. Activa `Enforce HTTPS` cuando esté disponible.

## Personalización pendiente

- Cambiar `hola@inventamoslabs.com` si se usará otra casilla.
- Agregar URL real de Cromora y EntreGO cuando estén públicas.
- Agregar imágenes reales, videos o mockups cuando estén listos.
